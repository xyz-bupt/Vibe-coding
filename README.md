# Vibe-Coding

> 氛围编程 - 使用 AI 工具辅助代码开发

## 简介

使用 AI（如 Claude、GPT 等）辅助编程的项目集合。

## 项目列表

### App 应用

| 项目 | 简介 |
|------|------|
| [brain-dump-space](./app/brain-dump-space/) | 闪念胶囊 - 极简思维记录工具，支持AI智能标签和思维星空可视化 |
| [MeowSimulator](./app/MeowSimulator/) | 猫娘模拟器 - 自动给聊天消息加喵～，支持 Android / macOS / Windows |
| [BrowserClaw](./app/BrowserClaw/) | 浏览器抓取扩展 - 基于React和Vite的Chrome扩展开发项目 |
| [audio-visualizer](./app/audio-visualizer/) | 音频可视化器 - 基于WebGL粒子系统和实时音频分析的沉浸式可视化 |
| [code-city-3d](./app/code-city-3d/) | 代码城市 - 将本地代码仓库可视化为赛博朋克风格的3D城市 |
| [content-workbench](./app/content-workbench/) | 内容工作台 - 管理多渠道内容任务和发布计划 |
| [focus-mode-extension](./app/focus-mode-extension/) | 专注模式 - 浏览器扩展，屏蔽网页干扰内容提升阅读体验 |
| [pomodoro-todo-app](./app/pomodoro-todo-app/) | 番茄待办 - 结合番茄工作法和任务管理的效率工具 |
| [word-pdf-converter](./app/word-pdf-converter/) | 文档转换 - PDF与Word文档双向转换工具 |

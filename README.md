## 简介

Vibe-Coding 是一系列注重用户体验和视觉氛围的小型应用的集合。每个项目都专注于解决特定问题，同时保持优雅的交互和美观的界面。

## 项目列表

### app/brain-dump-space
> 闪念胶囊 - 极简思维捕捉与可视化

一个极简主义的本地闪念记录与可视化工具。输入文字，自动转化为胶囊状节点飞入"思维星空"，支持 AI 智能标签提取。

- **技术**: React + TypeScript + Vite + Tailwind CSS
- **特色**: 力导向图可视化、轨道旋转动画、AI 自动标签
- **运行**: `cd app/brain-dump-space && npm install && npm run dev`

### app/pomodoro-todo-app
> 番茄钟待办 - 专注与任务管理

结合番茄工作法的待办事项应用，帮助保持专注并高效完成任务。

- **技术**: React + TypeScript
- **特色**: 番茄钟计时、任务管理、统计追踪

### app/focus-mode-extension
> 专注模式扩展 - 浏览器沉浸式体验

浏览器扩展，提供沉浸式的专注模式，屏蔽干扰元素。

- **技术**: Chrome Extension API
- **特色**: 页面元素屏蔽、专注计时

### app/word-pdf-converter
> 文档转换工具 - Word 与 PDF 互转

简洁的文档格式转换工具。

- **技术**: Node.js
- **特色**: 批量转换、格式保持

### app/content-workbench
> 内容工作台 - 写作与编辑辅助

为内容创作者设计的辅助工具集。

- **技术**: React
- **特色**: 文本处理、格式化工具

### Game/中国象棋
> 中国象棋 - 经典棋类游戏

经典中国象棋游戏的数字化实现。

- **技术**: React
- **特色**: 完整规则、AI 对战

## 快速开始

每个项目都是独立的，可以单独运行：

```bash
# 进入感兴趣的项目目录
cd app/<project-name>

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

## 开发理念

- **Vibe First**: 用户体验和视觉氛围优先
- **Minimal Design**: 简洁而不简单
- **Local First**: 尽可能使用本地存储，保护隐私
- **Type Safe**: 全面使用 TypeScript

# Vibe-Coding

> 氛围编程 - 在合适的氛围中写代码

## 简介

Vibe-Coding 是个人项目集合，包含了各类小应用、游戏和学习笔记。核心想法很简单：写代码需要氛围，好的氛围让编程更享受。

## 目录结构

```
Vibe-Coding/
├── app/                        # 前端应用
│   ├── brain-dump-space/       # 闪念胶囊 - 思维记录与可视化
│   ├── pomodoro-todo-app/      # 番茄钟待办
│   ├── focus-mode-extension/   # 专注模式浏览器扩展
│   ├── content-workbench/      # 内容工作台
│   └── word-pdf-converter/     # 文档转换工具
├── Game/                       # 游戏项目
│   ├── 中国象棋游戏/
│   ├── ai-snake-poet/
│   ├── chess-layout-*/
│   └── ...
└── 后端学习/                   # Flask 后端学习笔记
    ├── 01-Flask简介与安装.md
    ├── 02-基础概念.md
    └── ...
```

## 快速开始

```bash
# 运行某个应用
cd app/brain-dump-space
npm install
npm run dev
```

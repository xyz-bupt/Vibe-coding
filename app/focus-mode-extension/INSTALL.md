# 快速安装指南

## 专注模式浏览器扩展安装步骤

### 方法一：Chrome/Edge 开发者模式安装（推荐）

#### Chrome 浏览器
1. **下载项目**
   ```bash
   cd /Users/abc/Vibe-coding/app/focus-mode-extension
   ```

2. **打开扩展管理页面**
   - 在地址栏输入: `chrome://extensions/`
   - 或通过菜单: 更多工具 → 扩展程序

3. **启用开发者模式**
   - 点击右上角的"开发者模式"开关

4. **加载扩展**
   - 点击"加载已解压的扩展程序"按钮
   - 选择项目文件夹: `/Users/abc/Vibe-coding/app/focus-mode-extension`
   - 点击"选择文件夹"

5. **验证安装**
   - 扩展图标应出现在浏览器工具栏
   - 点击图标测试弹出窗口

#### Edge 浏览器
1. 重复上述步骤
2. 访问: `edge://extensions/`
3. 其他步骤相同

### 方法二：打包安装

#### 创建扩展包
```bash
cd /Users/abc/Vibe-coding/app/focus-mode-extension
zip -r focus-mode-extension.zip . -x "*.git*" "node_modules/*" "*.md"
```

#### 在浏览器中安装
1. 访问 `chrome://extensions/`
2. 启用"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 解压 zip 文件并选择解压后的文件夹

## 验证安装

运行验证脚本:
```bash
node verify-installation.js
```

应该看到所有检查都通过。

## 首次使用

1. **访问任意网页**
   - 例如: https://example.com 或任何新闻网站

2. **启用专注模式**
   - 点击浏览器工具栏中的扩展图标
   - 点击"启用专注模式"按钮
   - 或使用快捷键: `Ctrl+Shift+F` (Mac: `Cmd+Shift+F`)

3. **体验效果**
   - 广告、侧边栏等干扰内容将被移除
   - 只保留文章正文和核心内容

4. **自定义设置**
   - 点击扩展图标
   - 点击"高级设置"
   - 调整字体大小、行高等参数

## 常见问题

### Q: 扩展无法加载？
**A:** 检查是否选择了正确的文件夹，应包含 manifest.json 文件。

### Q: 图标显示异常？
**A:** 确认 icons 文件夹中包含所有尺寸的 PNG 图标文件。

### Q: 专注模式无法启动？
**A:** 尝试刷新页面，或检查浏览器控制台是否有错误信息。

### Q: 如何卸载？
**A:** 访问 `chrome://extensions/`，找到扩展，点击"移除"。

## 更新扩展

当您修改了代码后：
1. 访问 `chrome://extensions/`
2. 找到"专注模式"扩展
3. 点击刷新图标 🔄
4. 或按 `Ctrl+R` 刷新扩展

## 开发模式

如需调试扩展：
1. 访问 `chrome://extensions/`
2. 找到"专注模式"扩展
3. 点击"检查视图":
   - **background page**: 调试后台脚本
   - **popup.html**: 调试弹出页面
4. 对于内容脚本，在网页上按 F12 打开开发者工具

## 权限说明

扩展需要以下权限：
- **activeTab**: 访问当前标签页以应用专注模式
- **storage**: 保存用户设置
- **tabs**: 管理标签页状态

这些权限仅用于核心功能，不会收集任何用户数据。

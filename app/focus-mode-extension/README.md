# 专注模式 - Focus Mode

一个强大的浏览器扩展，帮助您屏蔽网页上的干扰内容，提供专注的阅读体验。

## 功能特性

### 核心功能
- **智能内容提取** - 自动识别并提取文章正文内容
- **干扰屏蔽** - 移除广告、侧边栏、评论、推荐等干扰元素
- **一键切换** - 快速开启/关闭专注模式
- **快捷键支持** - 使用 `Ctrl+Shift+F` (Mac: `Cmd+Shift+F`) 快速切换

### 阅读优化
- **可调字体大小** - 支持 14px 到 24px 的字体大小调整
- **行高调节** - 自定义行间距，提升阅读舒适度
- **护眼模式** - 减少蓝光，保护眼睛健康
- **响应式设计** - 适配不同屏幕尺寸

### 高级功能
- **白名单模式** - 只在指定网站启用专注模式
- **黑名单模式** - 在指定网站禁用专注模式
- **自定义选择器** - 添加自定义 CSS 选择器来屏蔽特定元素
- **自动启用** - 可设置访问网站时自动开启专注模式

## 安装方法

### Chrome/Edge (开发者模式安装)

1. 下载或克隆此项目到本地
2. 打开 Chrome/Edge 浏览器
3. 访问扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
4. 启用右上角的"开发者模式"
5. 点击"加载已解压的扩展程序"
6. 选择项目文件夹 `focus-mode-extension`
7. 扩展安装完成！

## 使用说明

### 基本使用

1. **启用专注模式**
   - 点击浏览器工具栏中的扩展图标
   - 在弹出窗口中点击"启用专注模式"按钮
   - 或使用快捷键 `Ctrl+Shift+F` (Mac: `Cmd+Shift+F`)

2. **禁用专注模式**
   - 再次点击扩展图标
   - 点击"禁用专注模式"按钮
   - 或使用相同的快捷键
   - 或点击页面右上角的关闭按钮

3. **访问设置**
   - 点击扩展图标，然后点击"高级设置"
   - 或右键点击扩展图标，选择"选项"

### 设置说明

#### 通用设置
- **自动启用** - 勾选后，访问网页时会自动开启专注模式
- **护眼模式** - 启用后会添加暖色滤镜，减少蓝光

#### 阅读设置
- **字体大小** - 拖动滑块调整正文字体大小 (14-24px)
- **行高** - 调整行间距以优化阅读体验 (1.4-2.2)

#### 白名单
- 只在列表中的网站启用专注模式
- 支持通配符匹配，例如：
  - `*.example.com` - 匹配 example.com 的所有子域名
  - `example.com/blog/*` - 匹配特定路径

#### 黑名单
- 在列表中的网站不启用专注模式
- 使用方法与白名单相同

#### 自定义选择器
- 添加额外的 CSS 选择器来隐藏元素
- 多个选择器用逗号分隔
- 例如：`.my-ad-class, #promo-banner, .sidebar-widget`

### 右键菜单

在任何网页上右键点击，选择"切换专注模式"即可快速开关。

## 注意事项

1. **某些网页可能无法正常工作**
   - 使用 Shadow DOM 的网站
   - 单页应用 (SPA) 可能需要刷新页面
   - 动态加载内容的网站可能效果不佳

2. **性能影响**
   - 专注模式会创建页面内容的副本
   - 对于超长页面可能会有轻微延迟

3. **内容提取**
   - 扩展会尝试智能识别主要内容
   - 如果提取不准确，可以在设置中添加自定义选择器

## 开发说明

### 修改样式

编辑 `styles.css` 文件来自定义专注模式的外观。

### 添加新的干扰选择器

在 `content.js` 中的 `DISTRACTION_SELECTORS` 数组中添加新的选择器。

### 调试

1. 访问 `chrome://extensions/`
2. 找到"专注模式"扩展
3. 点击"检查视图"来调试不同的脚本：
   - 背景页面
   - 弹出页面
   - 内容脚本（在网页的开发者工具中）

## 常见问题

**Q: 专注模式无法启动？**
A: 尝试刷新页面，或检查是否在黑名单中。

**Q: 内容提取不完整？**
A: 可以在设置中使用自定义选择器来调整提取规则。

**Q: 如何禁用某个网站的专注模式？**
A: 将该网站添加到黑名单中。

**Q: 快捷键不工作？**
A: 检查浏览器设置中是否与其他扩展冲突，或在 `chrome://extensions/shortcuts` 中重新配置。

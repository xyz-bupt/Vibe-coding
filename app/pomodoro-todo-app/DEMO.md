# 功能演示

## 1. 计时器功能

### 基本操作

1. **开始/暂停计时**
   - 点击"开始"按钮
   - 或按 `Space` 键
   - 计时器开始倒计时，进度环显示进度

2. **重置计时器**
   - 点击"重置"按钮
   - 或按 `Alt + R`
   - 计时器恢复到初始状态

3. **跳过当前时段**
   - 点击"跳过"按钮
   - 当前时段立即完成

### 模式切换

1. **专注模式** (🍅)
   - 默认 25 分钟
   - 用于专注工作
   - 快捷键：`Alt + 1`

2. **短休息模式** (☕)
   - 默认 5 分钟
   - 番茄钟之间的短暂休息
   - 快捷键：`Alt + 2`

3. **长休息模式** (🌴)
   - 默认 15 分钟
   - 完成 4 个番茄钟后的长休息
   - 快捷键：`Alt + 3`

### 自动切换

- 完成番茄钟后自动切换到休息模式
- 完成休息后自动切换回专注模式
- 每 4 个番茄钟后切换到长休息

## 2. 任务管理

### 创建任务

1. 点击"添加任务"按钮（或 `Alt + N`）
2. 填写任务信息：
   - 标题（必填，最多 100 字符）
   - 描述（可选，最多 500 字符）
   - 预计番茄数（1-20）
   - 优先级（低/中/高）
3. 点击"保存任务"

### 管理任务

1. **完成任务**
   - 点击任务前的复选框
   - 任务标记为完成，显示删除线

2. **编辑任务**
   - 点击编辑按钮（✏️）
   - 修改任务信息
   - 保存更改

3. **删除任务**
   - 点击删除按钮（🗑️）
   - 确认删除

4. **开始专注**
   - 点击播放按钮（▶️）
   - 任务激活为当前任务
   - 开始番茄钟计时

### 任务过滤

- **全部** - 显示所有任务
- **进行中** - 仅显示未完成的任务
- **已完成** - 仅显示已完成的任务

### 任务排序

任务按创建时间倒序排列（最新的在前）

## 3. 统计面板

### 实时统计

1. **今日番茄**
   - 显示今天完成的番茄钟数量
   - 实时更新

2. **专注时长**
   - 显示今天的总专注时间（分钟）
   - 自动计算（番茄数 × 25）

3. **完成任务**
   - 显示今天完成的任务数量
   - 实时更新

4. **每日目标**
   - 显示当前进度 / 目标
   - 默认目标：8 个番茄钟
   - 可在设置中修改

### 周日历热力图

- 显示本周 7 天的番茄钟数量
- 今天高亮显示
- 每天显示完成的番茄钟数

## 4. 设置

### 计时器设置

1. **专注时长** (1-60 分钟)
   - 设置单个番茄钟的时长

2. **短休息时长** (1-30 分钟)
   - 设置短休息的时长

3. **长休息时长** (1-60 分钟)
   - 设置长休息的时长

4. **长休息间隔** (2-10 个番茄)
   - 设置多少个番茄钟后进入长休息

5. **每日目标** (1-20 个番茄)
   - 设置每天的目标番茄钟数量

### 通知设置

1. **启用浏览器通知**
   - 允许发送桌面通知
   - 需要用户授权

2. **启用提示音**
   - 计时完成时播放提示音
   - 使用 Web Audio API

3. **自动开始休息**
   - 番茄钟完成后自动开始休息

4. **自动开始专注**
   - 休息完成后自动开始新的番茄钟

### 外观设置

1. **主题选择**
   - 浅色 - 浅色主题
   - 深色 - 深色主题
   - 跟随系统 - 自动切换

## 5. 通知系统

### Toast 通知

应用使用 Toast 通知提供反馈：

- **成功** (✓) - 绿色，操作成功
- **错误** (✕) - 红色，操作失败
- **警告** (⚠) - 橙色，需要确认
- **信息** (ℹ) - 蓝色，一般信息

### 通知示例

1. 创建任务
   ```
   ✓ 任务已创建
   "完成报告" 已添加到列表
   ```

2. 番茄钟完成
   ```
   ✓ 番茄钟完成！
   已完成 3 个番茄钟，休息一下吧！
   ```

3. 计时器操作
   ```
   ℹ 计时已暂停
   剩余时间：15:23
   ```

## 6. 键盘快捷键

### 查看所有快捷键

按 `?` 键打开快捷键帮助对话框

### 常用快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Space` | 开始/暂停 | 在非输入框状态下 |
| `Alt + R` | 重置 | 重置当前计时器 |
| `Alt + S` | 设置 | 打开设置对话框 |
| `Alt + N` | 新任务 | 打开新建任务对话框 |
| `Alt + 1` | 专注模式 | 切换到番茄钟模式 |
| `Alt + 2` | 短休息 | 切换到短休息模式 |
| `Alt + 3` | 长休息 | 切换到长休息模式 |
| `Esc` | 关闭 | 关闭当前对话框 |
| `?` | 帮助 | 显示快捷键帮助 |

## 使用场景

### 场景 1：专注工作

1. 创建任务："完成项目报告"
2. 设置预计番茄数：4
3. 点击播放按钮激活任务
4. 按 Space 开始番茄钟
5. 专注工作 25 分钟
6. 休息 5 分钟
7. 重复直到完成

### 场景 2：快速任务

1. 创建任务："回复邮件"
2. 设置预计番茄数：1
3. 开始计时
4. 快速完成

### 场景 3：长期项目

1. 创建多个子任务
2. 设置优先级
3. 每天完成几个番茄钟
4. 查看统计追踪进度

## 最佳实践

### 1. 任务管理

- 将大任务拆分成小任务
- 合理估算番茄数
- 设置合适的优先级

### 2. 专注技巧

- 25 分钟内专注于一个任务
- 避免多任务处理
- 休息时远离屏幕

### 3. 目标设定

- 从小目标开始（如 4 个番茄/天）
- 逐步增加目标
- 保持连续性

### 4. 数据追踪

- 定期查看统计
- 分析专注模式
- 调整工作习惯

## 路由详解

### 什么是路由？

路由（Routing）是将 URL 映射到 Python 函数的过程。当用户访问某个 URL 时，Flask 会根据路由规则找到对应的视图函数并执行。

### 基本路由

```python
from flask import Flask

app = Flask(__name__)

# 最简单的路由
@app.route('/')
def index():
    return '首页'

# 多级路由
@app.route('/about/company')
def company():
    return '公司介绍'

if __name__ == '__main__':
    app.run(debug=True)
```

### 路由规则

#### 1. 固定规则
```python
@app.route('/blog')
def blog():
    return '博客列表'

@app.route('/blog/post-1')
def blog_post1():
    return '第一篇文章'
```

#### 2. 动态路由（URL 变量）

动态路由允许 URL 中包含变量部分。

```python
# 基本语法：<变量名>
@app.route('/user/<username>')
def show_user_profile(username):
    return f'用户：{username}'

# 指定类型：<类型:变量名>
@app.route('/post/<int:post_id>')
def show_post(post_id):
    return f'文章 ID：{post_id}'

# 多个变量
@app.route('/user/<username>/post/<int:post_id>')
def user_post(username, post_id):
    return f'用户 {username} 的文章 {post_id}'
```

**支持的类型转换器**：
- `string` - 字符串（默认）
- `int` - 整数
- `float` - 浮点数
- `path` - 路径（可以包含斜杠）
- `uuid` - UUID 字符串

```python
from flask import Flask
from uuid import UUID

app = Flask(__name__)

@app.route('/page/<string:page_name>')
def page(page_name):
    return f'页面名称：{page_name}'

@app.route('/price/<float:price>')
def price(price):
    return f'价格：{price} 元'

@app.route('/file/<path:filepath>')
def file(filepath):
    return f'文件路径：{filepath}'

@app.route('/item/<uuid:item_id>')
def item(item_id):
    return f'物品 UUID：{item_id}'
```

#### 3. URL 构建与反转

使用 `url_for()` 函数生成 URL，避免硬编码。

```python
from flask import Flask, url_for, redirect

app = Flask(__name__)

@app.route('/')
def index():
    # 使用 url_for 生成 URL
    return f'''
    <h1>首页</h1>
    <a href="{url_for('about')}">关于我们</a><br>
    <a href="{url_for('profile', username='zhangsan')}">查看用户资料</a><br>
    <a href="{url_for('post', post_id=42)}">查看文章</a>
    '''

@app.route('/about')
def about():
    return '关于页面'

@app.route('/user/<username>')
def profile(username):
    return f'用户：{username}'

@app.route('/post/<int:post_id>')
def post(post_id):
    return f'文章 ID：{post_id}'

# URL 反转用于重定向
@app.route('/old-about')
def old_about():
    # 重定向到新的 URL
    return redirect(url_for('about'))
```

**使用 `url_for()` 的好处**：
- 避免硬编码 URL
- 修改路由时只需要修改一处
- 自动处理特殊字符转义
- 支持外部 URL

### HTTP 方法

HTTP 定义了多种请求方法，最常用的是 GET 和 POST。

#### GET 请求

GET 用于获取数据，参数通过 URL 传递。

```python
from flask import Flask, request

app = Flask(__name__)

# 只接受 GET 请求（默认）
@app.route('/search', methods=['GET'])
def search():
    # 获取 URL 参数
    keyword = request.args.get('keyword', '')
    page = request.args.get('page', 1, type=int)

    return f'搜索关键词：{keyword}，页码：{page}'

# 访问：/search?keyword=flask&page=2
```

#### POST 请求

POST 用于提交数据，数据在请求体中。

```python
from flask import Flask, request

app = Flask(__name__)

@app.route('/login', methods=['POST'])
def login():
    # 获取表单数据
    username = request.form.get('username')
    password = request.form.get('password')

    # 验证逻辑（后续章节会详细讲解）
    if username == 'admin' and password == '123456':
        return '登录成功'
    else:
        return '登录失败', 401  # 返回状态码

# 测试方法：使用 curl 或 Postman
# curl -X POST http://localhost:5000/login -d "username=admin&password=123456"
```

#### 完整的 HTTP 方法示例

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

# RESTful API 示例：管理文章
@app.route('/api/posts', methods=['GET', 'POST'])
def posts():
    if request.method == 'GET':
        # 获取文章列表
        return jsonify({'message': '获取文章列表'})
    elif request.method == 'POST':
        # 创建新文章
        data = request.get_json()  # 获取 JSON 数据
        return jsonify({'message': '创建文章', 'data': data}), 201

@app.route('/api/posts/<int:post_id>', methods=['GET', 'PUT', 'DELETE'])
def post_detail(post_id):
    if request.method == 'GET':
        # 获取单篇文章
        return jsonify({'message': f'获取文章 {post_id}'})
    elif request.method == 'PUT':
        # 更新文章
        data = request.get_json()
        return jsonify({'message': f'更新文章 {post_id}'})
    elif request.method == 'DELETE':
        # 删除文章
        return jsonify({'message': f'删除文章 {post_id}'}), 204

if __name__ == '__main__':
    app.run(debug=True)
```

**常用 HTTP 方法**：
- `GET` - 获取资源
- `POST` - 创建资源
- `PUT` - 更新整个资源
- `PATCH` - 部分更新资源
- `DELETE` - 删除资源
- `HEAD` - 获取响应头
- `OPTIONS` - 获取支持的方法

## 请求对象

Flask 通过 `request` 对象提供对请求数据的访问。

### 导入 request

```python
from flask import Flask, request

app = Flask(__name__)
```

### 获取请求数据

```python
@app.route('/demo', methods=['GET', 'POST'])
def demo():
    # 1. 获取 URL 参数（GET 请求）
    name = request.args.get('name')
    age = request.args.get('age', type=int)

    # 2. 获取表单数据（POST 请求，form-data）
    username = request.form.get('username')
    email = request.form['email']  # 如果不存在会报错

    # 3. 获取 JSON 数据（POST 请求，application/json）
    data = request.get_json()
    if data:
        title = data.get('title')

    # 4. 获取上传的文件
    file = request.files.get('avatar')
    if file:
        file.save(f'/path/to/save/{file.filename}')

    # 5. 获取请求信息
    method = request.method  # 请求方法
    url = request.url  # 完整 URL
    path = request.path  # 路径部分
    headers = request.headers  # 请求头
    user_agent = request.headers.get('User-Agent')
    ip = request.remote_addr  # 客户端 IP

    # 6. 获取 Cookie
    session_id = request.cookies.get('session_id')

    return '请求数据已接收'
```

### 完整示例：表单处理

```python
from flask import Flask, request, render_template_string

app = Flask(__name__)

# HTML 表单模板
LOGIN_FORM = '''
<!DOCTYPE html>
<html>
<head>
    <title>登录</title>
</head>
<body>
    <h1>用户登录</h1>
    <form method="POST" action="/login">
        <label>用户名：<input type="text" name="username" required></label><br><br>
        <label>密码：<input type="password" name="password" required></label><br><br>
        <button type="submit">登录</button>
    </form>
</body>
</html>
'''

@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'GET':
        # 显示登录表单
        return render_template_string(LOGIN_FORM)
    elif request.method == 'POST':
        # 处理登录请求
        username = request.form.get('username')
        password = request.form.get('password')

        # 简单验证（实际应用应该查询数据库）
        if username and password:
            return f'登录成功！欢迎，{username}'
        else:
            return '登录失败：请输入用户名和密码', 400

if __name__ == '__main__':
    app.run(debug=True)
```

## 响应对象

视图函数的返回值会自动转换为响应对象。

### 基本响应

```python
# 1. 返回字符串
@app.route('/text')
def text():
    return '这是纯文本响应'

# 2. 返回 HTML
@app.route('/html')
def html():
    return '<h1>这是 HTML 响应</h1><p>支持所有 HTML 标签</p>'

# 3. 返回元组（响应体, 状态码）
@app.route('/not-found')
def not_found():
    return '<h1>页面未找到</h1>', 404

# 4. 返回元组（响应体, 状态码, 响应头）
@app.route('/custom')
def custom():
    return '自定义响应', 200, {'X-Custom-Header': 'value'}
```

### 使用 make_response

```python
from flask import Flask, make_response

app = Flask(__name__)

@app.route('/advanced')
def advanced():
    # 创建响应对象
    response = make_response('<h1>高级响应</h1>')

    # 设置状态码
    response.status_code = 200

    # 设置响应头
    response.headers['X-Custom-Header'] = 'Custom Value'
    response.headers['Content-Type'] = 'text/html; charset=utf-8'

    # 设置 Cookie
    response.set_cookie('user_id', '12345', max_age=3600)

    return response
```

### JSON 响应

```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/api/data')
def get_data():
    data = {
        'name': '张三',
        'age': 25,
        'city': '北京',
        'hobbies': ['编程', '阅读', '旅行']
    }
    return jsonify(data)

# 设置状态码和响应头
@app.route('/api/user')
def get_user():
    user = {'id': 1, 'name': '李四'}
    return jsonify(user), 201, {'X-Custom-Header': 'value'}
```

## 重定向

重定向将用户导向另一个 URL。

```python
from flask import Flask, redirect, url_for

app = Flask(__name__)

@app.route('/')
def index():
    return '''
    <h1>首页</h1>
    <a href="/go-about">跳转到关于页面</a>
    '''

@app.route('/about')
def about():
    return '关于页面'

# 重定向到固定 URL
@app.route('/google')
def go_google():
    return redirect('https://www.google.com')

# 重定向到内部路由（推荐使用 url_for）
@app.route('/go-about')
def go_about():
    return redirect(url_for('about'))

# 带参数的重定向
@app.route('/user/<username>')
def user_profile(username):
    return f'用户：{username}'

@app.route('/redirect-user')
def redirect_user():
    return redirect(url_for('user_profile', username='zhangsan'))

# 临时重定向（302）vs 永久重定向（301）
@app.route('/old-page')
def old_page():
    # 永久重定向，搜索引擎会更新索引
    return redirect(url_for('new_page'), code=301)

@app.route('/new-page')
def new_page():
    return '新页面'
```

```python
from flask import Flask, abort, jsonify

app = Flask(__name__)

# API 错误处理

        'status_code': 400
    }), 400

@app.errorhandler(500)

        'message': '服务器内部错误',
        'status_code': 500
    }), 500

# 测试路由
@app.route('/api/users/<int:user_id>')
def get_user(user_id):
    if user_id < 1:
        # 返回 400 错误

    # 模拟用户不存在
    if user_id > 100:
        abort(404, description='用户不存在')

    return jsonify({'id': user_id, 'name': f'用户{user_id}'})
```

## 综合示例：用户管理系统

让我们把学到的知识整合起来：

```python
from flask import Flask, render_template_string, request, redirect, url_for, jsonify, session

app = Flask(__name__)
app.secret_key = 'your-secret-key-here'  # 用于 session 加密

# 模拟数据库
users_db = {
    1: {'id': 1, 'name': '张三', 'email': 'zhangsan@example.com'},
    2: {'id': 2, 'name': '李四', 'email': 'lisi@example.com'},
    3: {'id': 3, 'name': '王五', 'email': 'wangwu@example.com'}
}

# 首页
@app.route('/')
def index():
    return render_template_string('''
    <h1>用户管理系统</h1>
    <ul>
        <li><a href="/users">查看所有用户</a></li>
        <li><a href="/user/1">查看用户详情</a></li>
        <li><a href="/login">登录</a></li>
    </ul>
    ''')

# 获取所有用户（HTML 和 JSON）
@app.route('/users')
def users():
    # 根据 Accept 头返回不同格式
    if request.accept_mimetypes.accept_json:
        return jsonify(list(users_db.values()))
    return render_template_string('''
    <h1>用户列表</h1>
    <ul>
        {% for user in users %}
        <li>{{ user.name }} - {{ user.email }}</li>
        {% endfor %}
    </ul>
    <a href="/">返回首页</a>
    ''', users=list(users_db.values()))

# 获取单个用户
@app.route('/user/<int:user_id>')
def user_detail(user_id):
    user = users_db.get(user_id)
    if not user:
        return render_template_string('<h1>用户不存在</h1>'), 404

    return render_template_string('''
    <h1>用户详情</h1>
    <p>ID: {{ user.id }}</p>
    <p>姓名: {{ user.name }}</p>
    <p>邮箱: {{ user.email }}</p>
    <a href="/users">返回列表</a>
    ''', user=user)

# 登录表单
@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'GET':
        return render_template_string('''
        <h1>登录</h1>
        <form method="POST">
            <label>用户名：<input type="text" name="username" required></label><br><br>
            <label>密码：<input type="password" name="password" required></label><br><br>
            <button type="submit">登录</button>
        </form>
        ''')
    else:
        username = request.form.get('username')
        password = request.form.get('password')

        # 简单验证（实际应用应该查询数据库和验证密码哈希）
        if username == 'admin' and password == '123456':
            session['logged_in'] = True
            session['username'] = username
            return redirect(url_for('dashboard'))
        else:
            return '登录失败：用户名或密码错误', 401

# 仪表板（需要登录）
@app.route('/dashboard')
def dashboard():
    if not session.get('logged_in'):
        return redirect(url_for('login'))

    return render_template_string('''
    <h1>欢迎，{{ username }}！</h1>
    <p>这是你的仪表板</p>
    <a href="/logout">退出登录</a>
    ''', username=session.get('username'))

# 退出登录
@app.route('/logout')
def logout():
    session.clear()
    return redirect(url_for('index'))

# API: 创建用户
@app.route('/api/users', methods=['POST'])
def create_user():
    data = request.get_json()
    if not data or 'name' not in data or 'email' not in data:
        return jsonify({'error': '缺少必要参数'}), 400

    new_id = max(users_db.keys()) + 1
    new_user = {
        'id': new_id,
        'name': data['name'],
        'email': data['email']
    }
    users_db[new_id] = new_user

    return jsonify(new_user), 201

# 错误处理
@app.errorhandler(404)
def not_found(error):
    if request.accept_mimetypes.accept_json:
        return jsonify({'error': 'Not found'}), 404
    return render_template_string('<h1>404 - 页面未找到</h1>'), 404

if __name__ == '__main__':
    app.run(debug=True)
```

## 常见问题

### Q1: 为什么我的 URL 参数获取不到？

**问题**：
```python
# 访问 /search?keyword=flask
keyword = request.form.get('keyword')  # 错误！
```

**解决**：
```python
# URL 参数使用 request.args
keyword = request.args.get('keyword')  # 正确
```

### Q2: POST 请求返回 405 Method Not Allowed

**原因**：路由没有声明允许 POST 方法

**解决**：
```python
# 错误
@app.route('/submit')
def submit():
    pass

# 正确
@app.route('/submit', methods=['GET', 'POST'])
def submit():
    pass
```

### Q3: 如何处理可选的 URL 参数？

```python
# /api/users?page=2&limit=10
@app.route('/api/users')
```

### 练习 2：创建待办事项 API

实现基本的 CRUD 操作：
- GET `/api/todos` - 获取所有待办事项
- GET `/api/todos/<id>` - 获取单个待办事项
- POST `/api/todos` - 创建待办事项（JSON 格式）
- PUT `/api/todos/<id>` - 更新待办事项
- DELETE `/api/todos/<id>` - 删除待办事项

<details>
<summary>查看答案</summary>

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

# 模拟数据库
todos = {}
next_id = 1

@app.route('/api/todos', methods=['GET'])
def get_todos():
    return jsonify(list(todos.values()))

@app.route('/api/todos/<int:todo_id>', methods=['GET'])
def get_todo(todo_id):
    todo = todos.get(todo_id)
    if not todo:
        return jsonify({'error': '待办事项不存在'}), 404
    return jsonify(todo)

@app.route('/api/todos', methods=['POST'])
def create_todo():
    global next_id
    data = request.get_json()

    if not data or 'title' not in data:
        return jsonify({'error': '缺少 title 字段'}), 400

    todo = {
        'id': next_id,
        'title': data['title'],
        'completed': data.get('completed', False)
    }
    todos[next_id] = todo
    next_id += 1

    return jsonify(todo), 201

@app.route('/api/todos/<int:todo_id>', methods=['PUT'])
def update_todo(todo_id):
    todo = todos.get(todo_id)
    if not todo:
        return jsonify({'error': '待办事项不存在'}), 404

    data = request.get_json()
    if not data:
        return jsonify({'error': '没有数据'}), 400

    todo['title'] = data.get('title', todo['title'])
    todo['completed'] = data.get('completed', todo['completed'])

    return jsonify(todo)

@app.route('/api/todos/<int:todo_id>', methods=['DELETE'])
def delete_todo(todo_id):
    if todo_id not in todos:
        return jsonify({'error': '待办事项不存在'}), 404

    del todos[todo_id]
    return '', 204

if __name__ == '__main__':
    app.run(debug=True)
```
</details>

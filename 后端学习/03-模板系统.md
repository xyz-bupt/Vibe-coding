## 什么是 Jinja2？

Jinja2 是 Flask 默认使用的模板引擎。它的作用是：

- **分离逻辑和展示**：将业务逻辑（Python）和页面展示（HTML）分离
- **动态生成 HTML**：根据数据动态生成网页内容
- **代码复用**：通过模板继承和宏避免重复代码

### 为什么使用模板引擎？

**不使用模板**（不推荐）：
```python
@app.route('/user/<username>')
def user_profile(username):
    # HTML 和 Python 混在一起，难以维护
    return f'''
    <!DOCTYPE html>
    <html>
    <head>
        <title>用户资料 - {username}</title>
    </head>
    <body>
        <h1>欢迎，{username}</h1>
        <p>这是你的个人页面</p>
    </body>
    </html>
    '''
```

**使用模板**（推荐）：
```python
@app.route('/user/<username>')
def user_profile(username):
    # 代码清晰，易于维护
    return render_template('user.html', username=username)
```

### 显示变量

使用 `{{ variable }}` 语法显示变量。

```python
        'age': 25,
```

```html

<p>{{ hobbies[0] }}</p>
```

### 定义变量

在模板中使用 `set` 定义变量：

```html

<!-- 循环中定义变量 -->
{% for item in items %}
    {% set loop_index = loop.index %}
    <p>第 {{ loop_index }} 项：{{ item }}</p>
{% endfor %}
```

## 过滤器

过滤器用于修改变量的输出格式。

### 常用内置过滤器

```html
<!-- 安全过滤器（不转义 HTML） -->
{{ '<strong>粗体</strong>' | safe }}

<!-- 转义 HTML -->
{{ '<script>alert("XSS")</script>' | escape }}

<!-- 大小写转换 -->
{{ name | upper }}
{{ name | lower }}
{{ name | capitalize }}  <!-- 首字母大写 -->

<!-- 去除空格 -->
{{ text | trim }}

<!-- 格式化 -->
{{ price | float(2) }}  <!-- 保留两位小数 -->

<!-- 列表操作 -->
{{ items | first }}      <!-- 第一个元素 -->
{{ items | last }}       <!-- 最后一个元素 -->
{{ items | length }}     <!-- 列表长度 -->
{{ items | sort }}       <!-- 排序 -->
{{ items | reverse }}    <!-- 反转 -->

<!-- 字符串操作 -->
{{ text | replace('old', 'new') }}  <!-- 替换 -->
{{ text | truncate(20) }}           <!-- 截断 -->

<!-- 日期格式化 -->
{{ created_at | strftime('%Y-%m-%d') }}

<!-- URL 编码 -->
{{ url | urlencode }}

<!-- JSON 编码 -->
<script>
    const data = {{ user_data | tojson }};
</script>

<!-- 默认值 -->
{{ value | default('默认值') }}
{{ value or '默认值' }}  <!-- 简写 -->

<!-- 链式过滤器 -->
{{ name | striptags | trim | upper }}
```

## 控制结构

### if 语句

```html
{% if user %}
    <p>欢迎，{{ user.name }}！</p>
{% else %}
    <p>请先登录</p>
{% endif %}
```

**完整的条件判断**：
```html
{% if score >= 90 %}
    <p>优秀</p>
{% elif score >= 80 %}
    <p>良好</p>
{% elif score >= 60 %}
    <p>及格</p>
{% else %}
    <p>不及格</p>
{% endif %}
```

**判断变量是否存在**：
```html
{% if user is defined %}
    <p>用户：{{ user.name }}</p>
{% endif %}

{% if user is none %}
    <p>用户不存在</p>
{% endif %}

{% if items %}
    <p>有 {{ items | length }} 个项目</p>
{% else %}
    <p>没有项目</p>
{% endif %}
```

### for 循环

**基本循环**：
```html
<ul>
{% for item in items %}
    <li>{{ item }}</li>
{% endfor %}
</ul>
```

**遍历字典**：
```html
<dl>
{% for key, value in user_data.items() %}
    <dt>{{ key }}</dt>
    <dd>{{ value }}</dd>
{% endfor %}
</dl>
```

**循环变量（loop 对象）**：
```html
<table>
{% for user in users %}
    <tr>
        <td>{{ loop.index }}</td>          <!-- 当前索引（从1开始） -->
        <td>{{ loop.index0 }}</td>         <!-- 当前索引（从0开始） -->
        <td>{{ user.name }}</td>
        <td>{{ loop.first }}</td>          <!-- 是否第一次 -->
        <td>{{ loop.last }}</td>           <!-- 是否最后一次 -->
        <td>{{ loop.revindex }}</td>       <!-- 反向索引 -->
        <td>{{ loop.length }}</td>         <!-- 总数 -->
    </tr>
{% endfor %}
</table>
```

**循环中的 else**：
```html
<ul>
{% for user in users %}
    <li>{{ user.name }}</li>
{% else %}
    <li>没有用户</li>
{% endfor %}
</ul>
```

## 模板继承

模板继承允许你创建一个基础模板，子模板可以继承并覆盖其中的部分。

### 基础模板

**templates/base.html**：
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{% block title %}默认标题{% endblock %}</title>

    <!-- 可以被覆盖的 CSS 块 -->
    {% block extra_css %}
    <style>
        body { font-family: Arial, sans-serif; }
    </style>
    {% endblock %}
</head>
<body>
    <!-- 头部 -->
    <header>
        <h1>我的网站</h1>
        <nav>
            <a href="/">首页</a>
            <a href="/about">关于</a>
            <a href="/contact">联系</a>
        </nav>
    </header>

    <!-- 主要内容（子模板会覆盖这里） -->
    <main>
        {% block content %}
        <p>这是默认内容</p>
        {% endblock %}
    </main>

    <!-- 侧边栏（可选） -->
    <aside>
        {% block sidebar %}
        <h3>侧边栏</h3>
        {% endblock %}
    </aside>

    <!-- 页脚 -->
    <footer>
        <p>&copy; 2024 我的网站</p>
    </footer>

    <!-- 可以被覆盖的 JS 块 -->
    {% block extra_js %}
    {% endblock %}
</body>
</html>
```

### 子模板

**templates/index.html**：
```html
{% extends "base.html" %}

{% block title %}首页 - 我的网站{% endblock %}

{% block content %}
<h2>欢迎来到首页</h2>
<p>这是首页的内容。</p>
<ul>
    <li>功能 1</li>
    <li>功能 2</li>
    <li>功能 3</li>
</ul>
{% endblock %}

{% block sidebar %}
<h3>最新文章</h3>
<ul>
    <li><a href="/post/1">文章 1</a></li>
    <li><a href="/post/2">文章 2</a></li>
</ul>
{% endblock %}
```

**templates/user/profile.html**：
```html
{% extends "base.html" %}

{% block title %}用户资料 - {{ user.name }}{% endblock %}

{% block content %}
<div class="profile">
    <h2>{{ user.name }} 的资料</h2>
    <p>邮箱：{{ user.email }}</p>
    <p>城市：{{ user.city }}</p>
</div>
{% endblock %}

{% block extra_css %}
<style>
    {{ super() }}  <!-- 保留父模板的 CSS -->
    .profile {
        background: #f0f0f0;
        padding: 20px;
        border-radius: 5px;
    }
</style>
{% endblock %}
```

**调用父块的内容**：
```html

{% endblock %}
```

**多重继承**：
```html

<!-- base_admin.html -->

{% block content %}
    <div class="admin-panel">
        {% block admin_content %}{% endblock %}
    </div>
{% endblock %}

{% endblock %}
```

## 宏（Macro）

宏类似于函数，用于复用模板代码。

### 定义和使用宏

**templates/macros.html**：
```html
<!-- 定义表单输入宏 -->
{% macro input(name, value='', type='text', placeholder='') %}
    <div class="form-group">
        <label for="{{ name }}">{{ name | capitalize }}</label>
        <input
            type="{{ type }}"
            name="{{ name }}"
            id="{{ name }}"
            value="{{ value }}"
            placeholder="{{ placeholder }}"
            class="form-control"
        >
    </div>
{% endmacro %}

<!-- 定义按钮宏 -->
{% macro button(text, type='submit', class='btn-primary') %}
    <button type="{{ type }}" class="btn {{ class }}">
        {{ text }}
    </button>
{% endmacro %}

<!-- 定义渲染用户卡片宏 -->
{% macro user_card(user) %}
    <div class="user-card">
        <h3>{{ user.name }}</h3>
        <p>{{ user.email }}</p>
        <p>{{ user.city }}</p>
    </div>
{% endmacro %}
```

**使用宏**：
```html
<!-- 导入宏 -->
{% from 'macros.html' import input, button, user_card %}

<form method="POST">
    {{ input('username', placeholder='请输入用户名') }}
    {{ input('email', type='email', placeholder='请输入邮箱') }}
    {{ input('password', type='password', placeholder='请输入密码') }}
    {{ button('登录') }}
</form>

<!-- 渲染用户列表 -->
<div class="user-list">
    {% for user in users %}
        {{ user_card(user) }}
    {% endfor %}
</div>
```

### 带默认参数和变长参数的宏

```html
{% macro input(name, value='', type='text', **kwargs) %}
    <input
        type="{{ type }}"
        name="{{ name }}"
        value="{{ value }}"
        {% for key, value in kwargs.items() %}
            {{ key }}="{{ value }}"
        {% endfor %}
    >
{% endmacro %}

<!-- 使用 -->
{{ input('username', placeholder='用户名', class='form-control', required=true) }}
```

### 宏的上下文变量

```html
{% macro render_item(item) %}
    <li>{{ item }}</li>
{% endmacro %}

<!-- 访问调用者的上下文 -->
{% macro list(items) %}
    <ul>
    {% for item in items %}
        {% set caller_context = caller() %}
        <li>{{ item }} - {{ caller_context }}</li>
    {% endfor %}
    </ul>
{% endmacro %}
```

### 处理表单提交

**app.py**：
```python
from flask import Flask, render_template, request, redirect, url_for, flash

app = Flask(__name__)
app.secret_key = 'your-secret-key-here'

@app.route('/login', methods=['GET', 'POST'])
def login():
    error = None
    form_data = {}

    if request.method == 'POST':
        # 获取表单数据
        username = request.form.get('username')
        password = request.form.get('password')
        remember = request.form.get('remember')

        # 验证逻辑
        if not username:
            error = '请输入用户名'
        elif not password:
            error = '请输入密码'
        elif username != 'admin' or password != '123456':
            error = '用户名或密码错误'
        else:
            # 登录成功
            flash('登录成功！')
            return redirect(url_for('dashboard'))

        form_data = {'username': username}

    return render_template('login.html', error=error, form_data=form_data)

@app.route('/dashboard')
def dashboard():
    return '欢迎来到仪表板'
```

## 自定义过滤器

### 创建自定义过滤器

**app.py**：
```python
from flask import Flask

app = Flask(__name__)

# 自定义过滤器：货币格式化
@app.template_filter('currency')
def currency_format(value):
    return f'¥{value:,.2f}'

# 自定义过滤器：日期相对时间
@app.template_filter('time_ago')
def time_ago(datetime):
    from datetime import datetime as dt
    now = dt.now()
    diff = now - datetime

    if diff.days > 365:
        return f'{diff.days // 365} 年前'
    elif diff.days > 30:
        return f'{diff.days // 30} 个月前'
    elif diff.days > 0:
        return f'{diff.days} 天前'
    elif diff.seconds > 3600:
        return f'{diff.seconds // 3600} 小时前'
    elif diff.seconds > 60:
        return f'{diff.seconds // 60} 分钟前'
    else:
        return '刚刚'

# 自定义过滤器：截断并添加省略号
@app.template_filter('ellipsis')
def ellipsis(text, length=50):
    if len(text) > length:
        return text[:length] + '...'
    return text

# 使用
@app.route('/')
def index():
    return render_template(
        'index.html',
        price=12345.6789,
        created_at=datetime(2024, 1, 15),
        long_text='这是一段很长的文本内容...' * 10
    )
```

**在模板中使用**：
```html
<p>价格：{{ price | currency }}</p>
<p>创建于：{{ created_at | time_ago }}</p>
<p>{{ long_text | ellipsis(100) }}</p>
```

## 安全性

### XSS 防护

Jinja2 默认会转义所有 HTML 标签，防止 XSS 攻击。

```html
<!-- 自动转义 -->
{{ user_input }}  <!-- <script>alert('XSS')</script> 会被转义 -->

<!-- 信任内容（谨慎使用） -->
{{ trusted_html | safe }}

<!-- 在代码块中禁用自动转义 -->
{% autoescape false %}
    {{ user_input }}  <!-- 不会被转义 -->
{% endautoescape %}
```

### CSRF 防护

CSRF（跨站请求伪造）防护将在第6章《用户认证与授权》中详细讲解。

## 完整示例：博客系统

**app.py**：
```python
from flask import Flask, render_template, request, redirect, url_for, flash
from datetime import datetime

app = Flask(__name__)
app.secret_key = 'your-secret-key'

# 模拟数据库数据
posts = [
    {
        'id': 1,
        'title': 'Flask 入门教程',
        'content': 'Flask 是一个轻量级的 Python Web 框架...',
        'author': '张三',
        'created_at': datetime(2024, 1, 15),
        'views': 1234
    },
    {
        'id': 2,
        'title': 'Jinja2 模板引擎详解',
        'content': 'Jinja2 是 Flask 默认的模板引擎...',
        'author': '李四',
        'created_at': datetime(2024, 1, 16),
        'views': 567
    }
]

@app.route('/')
def index():
    return render_template('index.html', posts=posts)

@app.route('/post/<int:post_id>')
def post(post_id):
    post = next((p for p in posts if p['id'] == post_id), None)
    if not post:
        flash('文章不存在', 'danger')
        return redirect(url_for('index'))
    return render_template('post.html', post=post)

@app.route('/create', methods=['GET', 'POST'])
def create():
    if request.method == 'POST':
        title = request.form.get('title')
        content = request.form.get('content')
        author = request.form.get('author')

        if not title or not content:
            flash('标题和内容不能为空', 'danger')
        else:
            new_post = {
                'id': len(posts) + 1,
                'title': title,
                'content': content,
                'author': author or '匿名',
                'created_at': datetime.now(),
                'views': 0
            }
            posts.append(new_post)
            flash('文章发布成功！', 'success')
            return redirect(url_for('index'))

    return render_template('create.html')

if __name__ == '__main__':
    app.run(debug=True)
```

## 常见问题

### Q1: 如何处理多行文本显示？

**方法 1**：使用 CSS white-space
```html
<div style="white-space: pre-wrap;">{{ text }}</div>
```

**方法 2**：创建自定义过滤器
```python
@app.template_filter('newline_to_br')
def newline_to_br(text):
    return text.replace('\n', '<br>\n')
```

### Q2: 如何在 JavaScript 中使用模板变量？

```html
<script>
    // 使用 tojson 过滤器
    const user = {{ user | tojson }};
    console.log(user.name);

    // 或者使用 safe（谨慎使用，确保数据安全）
    const username = "{{ username | safe }}";
</script>
```

## 最佳实践

### 1. 总是使用模板继承

```html
<!-- 好的做法 -->
{% extends "base.html" %}
{% block content %}...{% endblock %}

<!-- 不好的做法 -->
<!DOCTYPE html>
<html>
<!-- 重复的基础 HTML -->
</html>
```

### 2. 使用宏复用表单元素

```html
<!-- 定义宏 -->
{% macro input(name, label) %}...{% endmacro %}

<!-- 使用宏 -->
{{ input('username', '用户名') }}
{{ input('email', '邮箱') }}
```

### 3. 模板中只包含展示逻辑

```html
<!-- 好的做法：模板只负责展示 -->
{% for user in users %}
    <li>{{ user.name }}</li>
{% endfor %}

<!-- 不好的做法：在模板中处理业务逻辑 -->
{% set filtered_users = [] %}
{% for user in all_users %}
    {% if user.active %}
        {{ filtered_users.append(user) }}
    {% endif %}
{% endfor %}
```

### 4. 使用有意义的变量名

```html
<!-- 好的做法 -->
{% for article in articles %}
    <h2>{{ article.title }}</h2>
{% endfor %}

<!-- 不好的做法 -->
{% for x in a %}
    <h2>{{ x.t }}</h2>
{% endfor %}
```

### 5. 提取可复用的组件

```
templates/

│   ├── header.html
│   ├── footer.html
│   ├── pagination.html
│   └── forms/
│       └── login_form.html
```

### 练习 2：创建分页组件

创建一个分页组件宏，使用时只需传入当前页和总页数。

<details>
<summary>查看答案</summary>

**templates/macros/pagination.html**：
```html
{% macro pagination(current_page, total_pages, base_url) %}
    {% if total_pages > 1 %}
        <div class="pagination">
            {% if current_page > 1 %}
                <a href="{{ base_url }}?page={{ current_page - 1 }}">上一页</a>
            {% endif %}

            {% for page in range(1, total_pages + 1) %}
                {% if page == current_page %}
                    <strong>{{ page }}</strong>
                {% else %}
                    <a href="{{ base_url }}?page={{ page }}">{{ page }}</a>
                {% endif %}
            {% endfor %}

            {% if current_page < total_pages %}
                <a href="{{ base_url }}?page={{ current_page + 1 }}">下一页</a>
            {% endif %}
        </div>
    {% endif %}
{% endmacro %}
```

**使用**：
```html
{% from 'macros/pagination.html' import pagination %}

{{ pagination(current_page=2, total_pages=10, base_url='/products') }}
```

## 开发 vs 生产环境

| 特性 | 开发环境 | 生产环境 |
|------|----------|----------|
| 服务器 | Flask 内置 | Gunicorn/uWSGI |
| Debug 模式 | True | False |
| 静态文件 | Flask 提供 | Nginx 提供 |
| 日志级别 | DEBUG | INFO/WARNING |
| 错误页面 | 详细错误信息 | 友好的错误页面 |

## Gunicorn 配置

### 安装

```bash
pip install gunicorn
```

### 基本使用

```bash
# 基本运行
gunicorn -w 4 -b 0.0.0.0:8000 app:app

# 参数说明
# -w 4: 4 个 worker 进程
# -b 0.0.0.0:8000: 绑定地址和端口
# app:app: 模块名:应用名
```

### 配置文件

**gunicorn.conf.py**：
```python
import multiprocessing

# 服务器绑定
bind = "0.0.0.0:8000"

# Worker 进程数（推荐：CPU 核心数 * 2 + 1）
workers = multiprocessing.cpu_count() * 2 + 1

# Worker 类型
worker_class = "sync"  # sync, gevent, eventlet

# 每个 worker 的线程数
threads = 2

# Worker 最大请求数（防止内存泄漏）
max_requests = 1000
max_requests_jitter = 50

# 超时时间
timeout = 30
keepalive = 2

# 日志
accesslog = "-"  # 标准输出
errorlog = "-"   # 标准输出
loglevel = "info"

# 进程名称
proc_name = "flask-app"
```

### 使用配置文件

```bash
gunicorn -c gunicorn.conf.py app:app
```

### Systemd 服务

**/etc/systemd/system/flask-app.service**：
```ini
[Unit]
Description=Flask Application
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/path/to/app
Environment="PATH=/path/to/venv/bin"
ExecStart=/path/to/venv/bin/gunicorn -c gunicorn.conf.py app:app
Restart=always

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
sudo systemctl start flask-app
sudo systemctl enable flask-app
sudo systemctl status flask-app
```

## Nginx 反向代理

### 安装 Nginx

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install nginx

# CentOS/RHEL
sudo yum install nginx
```

### 配置文件

**/etc/nginx/sites-available/flask-app**：
```nginx
server {
    listen 80;
    server_name example.com www.example.com;

    # 最大上传大小
    client_max_body_size 100M;

    # 静态文件
    location /static {
        alias /path/to/app/static;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 代理到 Gunicorn
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_redirect off;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }
}
```

启用配置：
```bash
sudo ln -s /etc/nginx/sites-available/flask-app /etc/nginx/sites-enabled/
sudo nginx -t  # 测试配置
sudo systemctl reload nginx
```

## Docker 容器化

### Dockerfile

**Dockerfile**：
```dockerfile
# 基础镜像
FROM python:3.11-slim

# 设置工作目录
WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    gcc \
    && rm -rf /var/lib/apt/lists/*

# 复制依赖文件
COPY requirements.txt .

# 安装 Python 依赖
RUN pip install --no-cache-dir -r requirements.txt

# 复制应用代码
COPY . .

# 创建非 root 用户
RUN useradd -m -u 1000 appuser && chown -R appuser:appuser /app
USER appuser

# 暴露端口
EXPOSE 8000

# 启动命令
CMD ["gunicorn", "-c", "gunicorn.conf.py", "app:app"]
```

### docker-compose.yml

**docker-compose.yml**：
```yaml
version: '3.8'

services:
  web:
    build: .
    ports:
      - "8000:8000"
    environment:
      - FLASK_ENV=production
      - DATABASE_URL=postgresql://user:password@db:5432/mydb
    depends_on:
      - db
    volumes:
      - ./static:/app/static
    restart: always

  db:
    image: postgres:15
    environment:
      - POSTGRES_USER=user
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=mydb
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: always

  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./static:/static
    depends_on:
      - web
    restart: always

volumes:
  postgres_data:
```

运行：
```bash
docker-compose up -d
```

## 环境变量管理

### 使用 python-dotenv

```bash
pip install python-dotenv
```

**.env**（不要提交到 Git）：
```env
FLASK_APP=app.py
FLASK_ENV=production
SECRET_KEY=your-secret-key
DATABASE_URL=postgresql://user:password@localhost/mydb
REDIS_URL=redis://localhost:6379/0
```

**.env.example**（提交到 Git）：
```env

FLASK_ENV=production
SECRET_KEY=change-me
DATABASE_URL=postgresql://user:password@localhost/mydb
REDIS_URL=redis://localhost:6379/0
```

**app.py**：
```python
from dotenv import load_dotenv
import os

load_dotenv()

app.config['SECRET_KEY'] = os.getenv('SECRET_KEY')
app.config['SQLALCHEMY_DATABASE_URI'] = os.getenv('DATABASE_URL')
```

## 日志记录

### 配置日志

```python
import logging
from logging.handlers import RotatingFileHandler
import os

# 确保日志目录存在
if not os.path.exists('logs'):
    os.mkdir('logs')

# 配置日志
logging.basicConfig(level=logging.INFO)

# 文件处理器（自动轮转）
file_handler = RotatingFileHandler(
    'logs/app.log',
    maxBytes=10240000,  # 10MB
    backupCount=10
)
file_handler.setFormatter(logging.Formatter(
    '%(asctime)s %(levelname)s: %(message)s [in %(pathname)s:%(lineno)d]'
))
file_handler.setLevel(logging.INFO)

# 添加处理器
app.logger.addHandler(file_handler)
app.logger.setLevel(logging.INFO)

app.logger.info('Flask 应用启动')
```

### 使用日志

```python
@app.route('/api/users')
def get_users():
    app.logger.info('获取用户列表')
    try:
        users = User.query.all()
        app.logger.info(f'找到 {len(users)} 个用户')
        return jsonify([u.to_dict() for u in users])
    except Exception as e:
        app.logger.error(f'获取用户失败: {str(e)}')
        return jsonify({'error': 'Internal error'}), 500
```

## 监控

### 健康检查

```python
@app.route('/health')
def health_check():
    """健康检查端点"""
    try:
        # 检查数据库连接
        db.session.execute(db.text('SELECT 1'))
        return jsonify({
            'status': 'healthy',
            'database': 'connected'
        }), 200
    except Exception as e:
        return jsonify({
            'status': 'unhealthy',
            'database': 'disconnected',
            'error': str(e)
        }), 503
```

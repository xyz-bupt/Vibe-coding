# Flask 快速参考手册

## 基础命令

### 安装 Flask
```bash
pip install flask
```

### 运行应用
```bash
python app.py
# 或
flask run
```

### 创建虚拟环境
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

## 常用代码片段

### 最小的 Flask 应用
```python
from flask import Flask
app = Flask(__name__)

@app.route('/')
def hello():
    return 'Hello, World!'

if __name__ == '__main__':
    app.run(debug=True)
```

### 路由定义
```python
# 基本路由
@app.route('/')
def index():
    return '首页'

# 带参数的路由
@app.route('/user/<username>')
def user(username):
    return f'用户：{username}'

# 限制类型
@app.route('/post/<int:post_id>')
def post(post_id):
    return f'文章 ID：{post_id}'

# HTTP 方法
@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        return '登录处理'
    return '登录表单'
```

### 请求处理
```python
from flask import request

# 获取 URL 参数
search = request.args.get('q', '')

# 获取表单数据
username = request.form.get('username')

# 获取 JSON 数据
data = request.get_json()

# 获取文件
file = request.files['file']
```

### 响应
```python
# 返回字符串
return 'Hello'

# 返回 HTML
return '<h1>Hello</h1>'

# 返回 JSON
from flask import jsonify
return jsonify({'key': 'value'})

# 返回带状态码
return 'Not Found', 404

# 重定向
from flask import redirect, url_for
return redirect(url_for('index'))
```

### 模板渲染
```python
from flask import render_template

# 渲染模板
return render_template('index.html', name='张三')

# 传递数据
return render_template('user.html', user=user_data)
```

### 数据库操作（SQLAlchemy）
```python
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy(app)

# 定义模型
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(80))

# 创建
user = User(name='张三')
db.session.add(user)
db.session.commit()

# 查询
users = User.query.all()
user = User.query.get(1)
user = User.query.filter_by(name='张三').first()

# 更新
user.name = '李四'
db.session.commit()

# 删除
db.session.delete(user)
db.session.commit()
```

### 用户认证（Flask-Login）
```python
from flask_login import LoginManager, login_user, logout_user, login_required, current_user

login_manager = LoginManager(app)

@login_manager.user_loader
def load_user(user_id):
    return User.query.get(int(user_id))

# 登录
login_user(user)

# 登出
logout_user()

# 保护路由
@app.route('/profile')
@login_required
def profile():
    return current_user.username
```

## 常用配置

```python
# 密钥
app.config['SECRET_KEY'] = 'your-secret-key'

# 数据库
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///app.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

# Session
app.config['PERMANENT_SESSION_LIFETIME'] = timedelta(days=7)

# 文件上传
app.config['UPLOAD_FOLDER'] = '/path/to/uploads'
app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024  # 16MB
```

## 常用装饰器

```python
# 路由装饰器
@app.route('/path')
def handler():
    pass

# HTTP 方法
@app.route('/', methods=['GET', 'POST'])

# 模板过滤器
@app.template_filter('reverse')
def reverse_filter(s):
    return s[::-1]

# 错误处理
@app.errorhandler(404)
def not_found(error):
    return 'Not Found', 404

# 请求前
@app.before_request
def before_request():
    pass

# 请求后
@app.after_request
def after_request(response):
    return response
```

## 数据库关系

```python
# 一对多
class User(db.Model):
    posts = db.relationship('Post', backref='author', lazy='dynamic')

class Post(db.Model):
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'))

# 多对多
post_tags = db.Table('post_tags',
    db.Column('post_id', db.Integer, db.ForeignKey('post.id')),
    db.Column('tag_id', db.Integer, db.ForeignKey('tag.id'))
)

class Post(db.Model):
    tags = db.relationship('Tag', secondary=post_tags,
                          backref=db.backref('posts', lazy='dynamic'))
```

## 常用状态码

| 状态码 | 含义 | 使用场景 |
|--------|------|----------|
| 200 | OK | 请求成功 |
| 201 | Created | 创建成功 |
| 204 | No Content | 删除成功 |
| 400 | Bad Request | 请求参数错误 |
| 401 | Unauthorized | 未认证 |
| 403 | Forbidden | 无权限 |
| 404 | Not Found | 资源不存在 |
| 500 | Internal Server Error | 服务器错误 |

## 常见问题

### 端口被占用
```python
app.run(port=8000)
```

### 模板找不到
确保 templates 文件夹在项目根目录

### 静态文件访问
放在 static 文件夹，访问路径：`/static/filename`

### 数据库迁移
```bash
pip install flask-migrate
flask db init
flask db migrate -m "message"
flask db upgrade
```

## 最佳实践

1. 使用虚拟环境
2. 永远不要在生产环境使用 debug=True
3. 使用环境变量存储敏感配置
4. 使用 requirements.txt 管理依赖
5. 为路由添加有意义的名称
6. 使用蓝图组织大型应用
7. 始终验证用户输入
8. 使用密码哈希，不要存储明文密码
9. 实施错误处理和日志记录
10. 编写测试
